# Regional extraction: finite structural reproducibility source

This source bundle contains seven Python graph/sampler modules and seven
test modules copied byte for byte from the research prototype. Independent
project code is available under the MIT license; see `LICENSE` and
`LICENSE_SCOPE.md`. Third-party notices and the original BSD-3-Clause text
are preserved separately.

This is a finite structural artifact. It is not the original E-morphic
implementation, a reproduction of its published physical results, or a
complete release of this project's physical experiments.

Public source: https://github.com/Maxwellabc/emorphic-regional-extraction

## Run the synthetic smoke test

Use Python 3.12 from this directory; no package installation is required:

```sh
python3.12 -I -B run_synthetic_smoke.py --report SYNTHETIC_SMOKE_RESULT.json
```

On Windows, use `py -3.12` in place of `python3.12`. The recorded run uses
Python 3.12.5. Isolated mode prevents imports from the surrounding checkout;
the runner adds only this bundle to the module search path. It verifies the
manifest before importing tests, checks the local import closure, and rejects
external process launches, network access and optional solver imports during
the smoke run. Standard Git metadata, Python caches and local `.omx` runtime
metadata are ignored by the file inventory; none is part of this artifact.

The suite discovers 74 tests and explicitly excludes two optional SciPy MILP
tests and one archived-circuit test. It runs 71 stdlib-only synthetic tests.
Use this command rather than unrestricted test discovery for that scope.
The optional `milp_extract` function remains in the unmodified laboratory
module and would require SciPy and NumPy if called separately.

The tests cover root-reachable DAG validation, shared costs, regional choices,
unreachable cycles, first-boundary cycle summaries, a full frozen-SCC
reference, and equality of eager/lazy sampler results and RNG states.
Synthetic costs and depth are structural proxies; e-class equivalence is an
input assumption. Passing tests does not establish logical equivalence,
mapped area, delay, power, speedup or superiority over a physical baseline.

## Contents and integrity

- `research/`: seven unmodified prototype modules: graph laboratory,
  baseline/regional sampling, first-hit filtering, conventional frozen-SCC
  reference and lazy integration.
- `tests/`: seven unmodified test modules. One excluded test retains a relative
  archived-development-data path; the referenced data is not included.
- `run_synthetic_smoke.py`: finite-suite wrapper and integrity/import checks.
- `SOURCE_MANIFEST.json`: relative paths, byte sizes, SHA256 digests and copy
  provenance. It excludes itself and the regenerable smoke report.
- `SYNTHETIC_SMOKE_RESULT.json`: the actual recorded run, regenerated by the
  command above.
- `LICENSE`, `LICENSE_SCOPE.md`, `THIRD_PARTY_NOTICES.md`, `third_party/`:
  project licensing, scope and original upstream attribution.

The two package initializers each contain one newline and no executable
statements; they and the packaging files are distinct from the copied source. The release ZIP checksum covers every packaged file, including
the manifest and smoke report. No ABC binary, library, circuit collection,
physical result, manuscript, private session, credential, validation split or
holdout split is included.

`.gitattributes` disables Git text conversion for every tracked file. The
manifest binds exact bytes, so clones and source archives must retain original
line endings rather than apply a machine's `core.autocrlf` setting. Do not
normalize these files without regenerating the manifest and validating a
fresh Git export.

The initial GitHub web upload normalized the generated smoke report from
CRLF to LF and represented each zero-byte initializer by a single LF. This
packaging revision reconciles the manifest with those uploaded bytes. All
fourteen prototype source/test modules and the third-party license remain
byte for byte unchanged. The published smoke report uses LF; regenerating
it on another platform may change line endings without changing its test
results. The report and manifest itself remain outside the manifest inventory.

The [E-morphic paper, v2](https://arxiv.org/html/2504.11574v2) and fixed
implementation describe the upstream flow. Full physical reproduction also
needs exact tool builds, library/input hashes, rewrite settings, seeds,
original-circuit CEC, commands and query/failure/timeout accounting. Those
are outside this finite artifact. A benchmark source pointer does not imply
that differently formatted files are byte-identical.

The larger research prototype used a SmoothE-artifact-inspired,
query-budget-adapted GA comparator, with population 3, tournament 2,
conditional replacement 0.7, crossover 0.8, mutation 0.8 and 3 paid initial
queries plus 9 pairs of children (21 mappings). Repeated/fallback candidates
remain paid and receive CEC. No GA implementation or GA physical result is
included here. This is not the complete differentiable SmoothE optimizer;
equal query budgets do not establish equal compute or causal isolation.
